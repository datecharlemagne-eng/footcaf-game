# Foot CAF Foot CAF est un prototype de jeu de gestion de football africain conçu pour représenter le football sur le continent avec : - gestion de club, - carrière joueur, - recrutement de talents, - championnats nationaux, - compétitions CAF, - finances club, - classement mondial, - notifications de résultats. ## Aperçu Le projet est un prototype jouable en navigateur, construit avec HTML, CSS et JavaScript vanilla. Il offre une interface de gestion de club avec : - tableau de bord de club, - effectif et progression des joueurs, - recrutement de talents africains, - classement des ligues nationales, - compétitions CAF, - finances, - classement mondial. ## Démarrage rapide 1. Ouvrez le projet dans un navigateur. 2. Cliquez sur l’index `index.html` ou lancez un petit serveur local : ```bash python -m http.server 8000 ``` 3. Accédez à : ```text http://localhost:8000 ``` ## Structure du projet ```text footcaf-game/ ├── index.html ├── styles.css ├── app.js ├── README.md └── assets/ ``` ## Fonctionnalités déjà présentes - Tableau de bord de club - Effectif et niveaux de joueurs - Recrutement de talents jeunes - Classement national et mondial - Gestion financière - Compétitions CAF et CAN - Simulateur hebdomadaire - Système de notifications ## Roadmap (MVP) - moteur de match 3D - sauvegarde de progression - multi-joueurs compétitifs en ligne - intégration de données de clubs nationaux complets - modélisation avancée des jeunes talents et acadèmies ## Licence MIT
