# footcaf-game

Foot CAF est un jeu de gestion de football africain. Le but est de construire un club compétitif, gérer le budget, faire grandir la réputation du club, préparer les matchs et recruter des talents.

## Ce qu’il contient

- Une interface de gestion de club
- Une équipe avec joueurs, morale et performance
- Un mercato simple pour recruter des talents
- Un système de simulation de match et d’entraînement
- Un journal de bord pour suivre les événements importants

## Lancer le jeu

Ouvrez simplement le fichier `index.html` dans un navigateur, ou servez le dossier localement :

```bash
python3 -m http.server 8000
```

Puis ouvrez http://localhost:8000 dans votre navigateur.

## Objectif

Gérer le club pour atteindre les sommets du championnat et de la Coupe CAF.
